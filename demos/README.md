# Demos

This `demos/` directory contains small examples of how you can use VexFlow.

Build the library from the main `vexflow/` directory:

- `npm install`
- `grunt`

The header comments for each source file explain how to run each demo.

The [Harbor duet score reader](ui/score-reader.html) demonstrates shared keyboard and pointer selection on SVG and Canvas. Build the debug bundle before opening the example. [Review instructions](../docs/vf6/m7.md#assistive-technology-review)

Run `npm run pdf` to generate the Minuet, Bach fugue, opening page of Chopin’s third Ballade, and [PDF library](../build/pdfs/index.html). Open the [eight-bar fugue](ui/bach-fugue.html) to follow the subject through its first three entries. [Print and upload commands](../docs/build.md#generate-and-upload-the-pdf-demos)
