## Render a conductor score and a part

Use the same declarative EasyScore composition for both views. Load the chosen music and text faces before measuring. Each call replaces the contents of its own container only after constructing the new pages. The return value contains a one-based page number, a physical SVG and the positions and source measures of its systems. All page coordinates are in millimeters.

```js
const { Publication } = VexFlow;
const book = new Publication(source); // EasyScoreCompositionSpec with staff and event IDs
const common = { paper: 'A4', title: 'Andante in G', footer: 'Andante in G' };

const score = book.render(scoreContainer, {
  ...common, staffSize: 7.8, subtitle: 'Flute, viola and violoncello',
  header: 'Andante in G · Score',
});
const cello = book.render(partContainer, {
  ...common, paper: 'Letter', staves: ['vc'], staffSize: 7.2,
  subtitle: 'Violoncello', header: 'Andante in G · Violoncello',
  systemBreaks: [17], preferredTurns: [16], forbiddenTurns: [13],
  regions: [{ kind: 'cue', staff: 'fl', measure: 16, label: 'Flute cue' }],
});

const liveSVG = cello.toSVG(1);
const portableSVG = cello.toSVG(1, outlineFonts);
const printDocument = cello.toPrintHTML(outlineFonts);
```

Open the returned HTML in its own document and print at 100%. In headless Chromium, load it with `page.setContent(printDocument)` and use `page.pdf({ preferCSSPageSize: true, printBackground: true })`. The HTML includes physical paper dimensions, zero printer margins and one SVG per page. The SVG already contains the music margins. Outlining requires a matching face for every glyph. A missing face raises `MissingFont`. [Portable font setup](../portable-svg.md) · [Complete 26-bar study](../../tests/engraving/publication-studies.mjs)

## How the page is chosen

| Choice | Behavior |
| --- | --- |
| Paper and staff size | Use `'A4'`, `'Letter'` or `{ width, height }`. Default staff height is 7 mm for four standard spaces. The default margins are 15 mm top and bottom and 16 mm on each side. |
| Page furniture | The title and subtitle occupy space on page one. Subsequent pages can use a running header. The footer and page number reserve bottom space. Set `pageNumbers: false` to omit numbers. |
| Vertical spacing | Format continuous systems to the music width, measure their envelopes and rendered ink, then pack them in source order. `systemGap` is the minimum gap. `maxExtraGap` caps added space on full pages. The last page keeps its minimum spacing unless `justifyLast` is enabled. |
| Page turns | `systemBreaks` and `pageBreaks` name the measure that starts the new system or page. `preferredTurns` and `forbiddenTurns` name the measure just **before** the turn. Among legal system boundaries, the planner minimizes forbidden turns, then page count, then turn difficulty and unused space. An entire measure of rests in all performing voices favors a turn. An explicit preference can identify another playable turn. |
| Part views | Select source staff IDs in `staves`. The view preserves source order. A note on an omitted display staff returns to its rhythmic staff. Relationships entirely outside the part drop out. A relationship crossing the selection boundary reports its source and measures. |
| Cues and ossias | A labeled region engraves one source measure as a small reference staff above that measure, at written pitch and with inherited clef, key and meter. Default scale is 70%. The original notes or rests remain in the performing voice. The region protects its host bar from multi-measure rest compression. |
| Export | Screen, standalone SVG and browser print use the same page and system positions. Outlined SVG retains per-page metadata containing the measures, staff and event identities, pitches, ticks, rests, printed text, span fragments and inset sources. Unnamed events also have a staff, measure, voice and event position. |

Inspect `result.diagnostics`. `ForbiddenTurn` identifies the bar where a forced or otherwise unavoidable turn conflicts with the view. `PageOverflow`, `SystemOverflow` and `TextOverflow` identify oversized music, insets or page furniture. An oversized system stays on its own page. The preview remains available for inspection and portable print requires resolving overflow. `ExcludedAnchor` identifies a partially selected source relationship. `Engraving` carries a diagnostic from the continuous layout.

This release path accepts declarative EasyScore sources and renders pages in a browser SVG DOM. Its part planner ranks turns at system boundaries. It has no tempo-based turn-time model. The printed insets align to the host measure horizontally. Each contains one written-pitch source bar with its own internal note spacing. Transposed cues, multi-bar ossias, duplex spreads and orchestral condensing remain separate work.
