## Constructing the notation

The map is reusable data. Its instrument IDs identify the members of an attack. The event ID identifies the attack itself across score and part views. The same note description works in a native voice, in EasyScore and in a publication source.

```js
const kit = new VexFlow.PercussionMap();
const backbeat = kit.note(['snare', 'hat'], 'q');
const native = new VexFlow.StaveNote(backbeat);
const easy = score.make.note(backbeat);
const part = {
  id: 'kit', clef: 'percussion',
  measures: [{ voices: [{ notes: [
    { id: 'backbeat', note: backbeat }, kit.note(['kick'], 'q'), kit.note(['hat'], 'h'),
  ] }] }],
};
```

Use `note.notation` for semantic inspection on either backend. A mixed kit chord gets an SVG accessible label containing both instrument names. Each publication page carries the IDs, labels and head indexes of its selected events in SVG metadata. The note's native `keys` still encode the display positions. Applications can map the named instruments to playback independently. LilyPond's percussion styles likewise distinguish instruments, staff positions and heads. [Percussion notation reference](https://lilypond.org/doc/v2.26/Documentation/notation/common-notation-for-percussion.html)

```js
const guitar = new VexFlow.FrettedInstrument('dropd', 2);
const pair = guitar.attack([{ str: 6, fret: 0 }], 'q');
const written = score.make.note(pair.note);
const tab = score.make.tabNote(pair.tab);
```

For a five-string banjo, use `new FrettedInstrument('standardBanjo')`. The fifth string begins at neck fret 5. TAB 0 sounds its open G5, and TAB 7 sounds A5. A positive fret below 5 is invalid on that string. The four full-length strings use their ordinary fret numbers. With a capo, displayed stops are relative to the capo and an open string sounds from the higher of its nut and the capo.

For a custom short string, `new Tuning('D/5,G/5', [0, 5])` records each nut in string-number order. A plain list of pitches uses fret zero for every nut.

Use the written pitches of the open strings for custom tuning. Standard guitar convention sounds an octave below these written pitches. Apply the desired accidental policy to the standard staff. The diagram's frets run from the lowest string on the left to the highest on the right. Barre endpoints use ordinary one-based string numbers. [MusicXML capo](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/capo/) · [MusicXML frame notes](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/frame-note/)

Pass `orientation: 'horizontal'` to put the nut at the left and the high string on top. Both orientations accept the same low-to-high fret array and one-based barre endpoints. The horizontal frame keeps finger numbers and its starting-fret label upright. Use `getBoundingBox()` to position a neighboring frame.

A chord frame can show left-hand finger numbers inside stopped-string dots. Supply `fingerings` in the same low-to-high order as `frets`. Use `null` for an open, muted, or unmarked string.

```js
const dMajor = new FretDiagram({ frets: ['x', 'x', 0, 2, 3, 2], fingerings: [null, null, null, 1, 3, 2] });
dMajor.setFingerings([null, null, null, null, 3, 2]); // Clear the G-string digit.
```

Use the same structured harmony as a lead-sheet symbol to choose a standard-guitar frame. The catalog includes open C, C/E, D and G. C also has a named `third-position` barre shape. Omit the name for the default open voicing. An unregistered tuning, harmony or named shape returns `undefined`. You can pass the preset name `standard` or its comma-separated written pitches, highest string first.

```js
const harmony = { root: 'C', bass: 'E' };
const shape = FretDiagram.lookupVoicing(harmony, 'standard');
if (shape) new FretDiagram(shape).setContext(ctx).setX(10).setY(10).draw();
```

For alternating tremolo, call `AlternatingTremolo.endpoint(description, strokes)` for each note before adding it to the voice. Construct the relationship with both native handles, then queue it with `factory.adopt(tremolo.setContext(factory.getContext()), 'drawable')`. A pair of written half notes consumes one half note in total. One to four strokes share the same voice timing. A whole-note pair fills a 4/4 bar and draws a floating stack between its heads. For a cross-staff pair, assign each note to its piano staff in the same voice. In native drawing, use `voice.preserveStaveAssignments = true` and call `voice.draw(ctx)`. The strokes meet both stem tips after each layout. The same adoption path works with a standalone fret diagram. [MusicXML tremolo](https://www.w3.org/2021/06/musicxml40/musicxml-reference/elements/tremolo/)

For a custom signature, call `new KeySignature('C').setOrdered(entries)` and attach it to the stave. Each entry supplies an accidental type and either a written pitch or a half-line position counted down from the top. A collection of edition presets can reuse those entries by name. [Written pitches and edition presets](../score-layout.md#written-pitches-in-custom-key-signatures) Supply explicit natural entries for cancellations on a signature change. A `WrittenAccidentalState` handles note accidentals inside a measure. An explicit courtesy request prints even if the sign is already in force. [Accidental vocabulary](https://www.w3.org/2021/06/musicxml40/musicxml-reference/data-types/accidental-value/)

## Independent meter decision

Keep the common-span contract for VF5 structured compositions. The spike first inserted ordinary bar notes into only the staff requiring a barline. That moved simultaneous attacks to different x positions. Formatting both voices on one clock and placing the three staff-local barlines between formatted attacks keeps all six onsets aligned. During the cadenza a hidden final quarter extends the lower voice's timing window. It creates no printed rest.

The prototype handles between-attack barlines in one formatted system. It does not decide where to cut a sustained note, synchronize changing tuplets, or split local bars at a system break. Budget **3–5 engineering weeks** for a VF6 prototype with rational staff-local bar tracks, local beaming and two-system reflow, plus **1–2 weeks** for adapter, repeat and review work. Re-estimate against a real imported passage before scheduling production support. [Time-model decisions](requirements/instrument-notation.md)

## Right-hand accordion registers

Attach a register to the note where the switch takes effect. Set `high` for the 4-foot reed, `middle` to the number of 8-foot reeds (0–3), and `low` for the 16-foot reed. Omitted ranks are silent. An empty setting draws the empty three-band frame.

```js
const middle = factory.AccordionRegister({ middle: 1 });
firstNote.addModifier(middle, 0);
secondNote.addModifier(factory.AccordionRegister({ high: true, low: true }), 0);
thirdNote.addModifier(factory.AccordionRegister({ middle: 2 }), 0);
```

The mark uses the score's music font. After formatting, `middle.getBoundingBox()` reports its drawn extent and `middle.getRanks()` returns the complete reed setting.

## Highland pipe embellishments

Attach a named grace group to the landing note before formatting the voice. In these light-music forms, a grip into low A uses low G, D, low G. A taorluath adds E before the landing. Both groups beam their written 32nd grace notes together. The landing note keeps its duration.

```js
firstLowA.addModifier(GraceNoteGroup.highland('grip'), 0);
secondLowA.addModifier(GraceNoteGroup.highland('taorluath'), 0);
```

For a variant, pass its complete sequence as the second argument, for example `GraceNoteGroup.highland('grip', ['b/4', 'd/5', 'g/4'])`. Read the movement with `getHighlandName()` and its notes with `getGraceNotes()`. Use the ordinary `GraceNoteGroup` constructor for an unnamed group.

## Movable four-shape major scales

Build the passage with its written pitches, key signature and durations. Call `StaveNote.applyFourShape(tonic, notes)` once before formatting. The written letter relative to the major tonic selects fa, sol, la, fa, sol, la or mi. Fa uses a right triangle oriented for the stem, sol an oval, la a square and mi a diamond.

```js
const scale = ['d/4', 'e/4', 'f#/4', 'g/4', 'a/4', 'b/4', 'c#/5', 'd/5'];
const notes = scale.map(key => factory.StaveNote({ keys: [key], duration: 'q', autoStem: true }));
stave.addKeySignature('D');
StaveNote.applyFourShape('D', notes);
```

The same written E is la in C major and sol in D major. The style follows spelled degrees across octaves and preserves explicit per-pitch head overrides.
