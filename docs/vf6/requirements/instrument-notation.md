# VF6 requirements · instrument notation

**2026-11-18 · Proposed from M6 VF5 implementation and browser tests.** Update a row when an adapter, engraving review or score-model decision supplies new evidence. [VF5 support and original scores](../m6.md)

| ID | Requirement or design choice | Verification / open decision |
| --- | --- | --- |
| INST-01 | Keep the event ID, instrument ID and head index independent. A kit maps each instrument to a written position, head and stem preference. It can also supply a printable legend and descriptive text. | Retrieve the same two kit instruments in a native note, SVG and exported part. Decide how multiple playing surfaces on one instrument should identify themselves. |
| INST-02 | A fretted event records tuning, capo, string and relative fret. Derive the written pitch using an explicit octave convention. Preserve the source positions when tuning changes. | Drop D, capo two, string six at fret zero produces written E3. Define separate harmonic touch, sounding pitch and muted-string data before inferring derived standard notation. |
| INST-03 | Store a logical tremolo with endpoint IDs, each written value, its occupied time, stroke count and measured/unmeasured intent. | Two written half notes span one half note at one, two or three strokes. Decide separate layout behavior for stemless notes, opposite stems, system breaks and unmeasured performance. |
| INST-04 | Technique, harmony and fingering information can carry semantic IDs and literal spelling. Preserve the literal label through layout and export. | Round trip a bowing mark, two different accidental conventions and an altered slash chord. Standardize a portable vocabulary and structured polychord stacks after adapter review. |
| INST-05 | A custom signature owns its ordered signs and written positions. Separate the sign, the pitch spelling, tuning and cancellation/cautionary policy. | Preserve the arbitrary order at draw and export. Suppress repeated signs by letter and octave within one staff. Specify simultaneous conflicting signs and clef remapping. |
| INST-06 | Keep rhythm and pitch helpers optional. Distinguish sounding pitch, written pitch, displayed key and explicit user overrides across an instrument change. | Check a pickup, compound or additive group cuts, tied cross-bar note, split rest and two enharmonic realizations of one interval. Define tuplets beyond the VF5 helper's 64th grid. |
| INST-07 | Staff-local bars and meters share a rational global clock. Silent padding for layout must remain distinct from a performed or printed rest. | Align six common attacks across 3/4 and 2/4. Prototype sustained notes, independently grouped beams, unequal spans, local repeats and breaks before extending the score API. |
| INST-08 | A fret frame has independent semantic data, staff-relative attachment and measured ink bounds. Bend phases retain prebend, hold and release identities and eventually exact musical offsets. | Check muted, open, stopped and barred strings. Review labels and fingerings with a guitarist. Define gesture timing and automatic label/frame clearance. |
