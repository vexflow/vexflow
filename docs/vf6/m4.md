## Using the VF5 API

Pass `continuous` to `EasyScore.compose()`. Give each staff an ID and each span endpoint an event ID. Continue using the native notes to add modifiers, styles and beams. Reflow with `result.sheet.setWidth(width).format()`. After resizing and clearing the drawing surface, call `factory.draw({ retain: true })` to draw the same score again. [Complete composition example](../easyscore.md#reflow-and-spans)

| Option | Engraving behavior |
| --- | --- |
| `mode` | The default, `balanced`, looks ahead from each legal break. It minimizes overflow first, then the sum of squared unused widths and a per-row cost. `greedy` fills each row in order. Both use the same measured signs, staff names and constraints. |
| `boundaries` | Measure numbers are one-based. Use `{ measure: 3, breakBefore: 'force' }` to start a row or `'keep'` to keep that measure with its predecessor. An inseparable group wider than the viewport retains its minimum width and reports overflow. |
| Row signatures | A fresh row carries the active clef and key. Meter appears at the start of the piece and at changes. The preceding row shows upcoming changes unless `courtesy: false`. Generated accidentals on tied arrivals respond to the break. Explicit accidentals stay attached. |
| Structural marks | `measureNumbers` shows the first source measure number on each row. A boundary can carry a boxed `rehearsal`, `repeatStart`, `repeatEnd` or navigation mark. D.S. and To Coda refer to a named segno or coda. Targets are checked at composition. |
| Staves and groups | Supply `name` and `shortName` on a staff. A measure's `instrument` changes that label. Use `groups: [{ first: 'rh', last: 'lh', type: 'brace', barlines: true }]` to group staves. A bracket is also available. |
| Silence | `hideEmptyStaves` chooses the visible staff map for each row. `compressRests` groups consecutive wholly silent, undecorated measures across the score. A boundary, instrument change, signature, decorated rest or spanning mark interrupts a run. Use `{ measure: n, keepRest: true }` to keep a particular bar visible. |
| Cross-staff notes | Events can name their target stave. A beam follows the final positions. A `splitChords` entry references two aligned notes with equal onset, duration and stem direction. Half notes, quarter notes and eighths with one beam owner are supported. A native arpeggio can use `stroke.addEndNote(lowerNote)`. |

## Spans, results and diagnostics

Declare logical relationships in `continuous.spans`. For example, `{ id: 'sustain', kind: 'pedal', from: 'l0', to: 'l3' }` follows both notes across any number of rows. Each fragment carries its source ID, row index, endpoints and role (`single`, `first`, `middle` or `last`). Widening the sheet joins the pieces again. [Span drawing rules](../../src/continuousspan.ts)

| Family | What survives a break |
| --- | --- |
| Ordinary beam | Each row fits its own stems and continues the beam toward the adjacent row. All attacks retain their written rhythm and source beam membership. |
| Pitched glissando | Use `{ id: 'slide', kind: 'glissando', from: 'a', to: 'b', fromHead: 1, toHead: 0 }` for two pitched attacks on one staff. Each head index defaults to zero. The line clears both heads and carries its slope through a system break. Set `wavy: true` for a row of waves that follows the pitch slope. Each fragment fits whole waves between its endpoints. |
| Dashed pitch tie | Set `dashed: true` on a continuous tie. Use `fromHead` and `toHead` to select the tied pitches. Each fragment draws an open dashed arc. On a native `StaveTie`, use `tie.setStyle({ lineDash: '4 3' })`. |
| Tie and slur | Note and optional chord-head indices stay fixed. Each row gets a separately fitted curve. Continuation heights follow the written pitch through a clef change. |
| Crescendo and diminuendo | The opening at an edge matches the opening on the next row, using the fraction of the full drawn width reached at the break. |
| Lyric extender and hyphen | The syllable appears on the first fragment. The extender or hyphen continues on subsequent rows. |
| Pedal, volta, ottava, trill and tuplet | Family-specific hooks, labels or extensions distinguish the opening, continuation and ending. Tuplet timing comes from the authored music. |

After formatting, inspect `result.sheet.getContinuousLayout()`. Its `rows` report source measure numbers, visible staff IDs, grouped rests and overflow. Its `fragments` give the positions used by both renderers. Its `diagnostics` identify the affected source measures and, where applicable, the mark. `RowOverflow` means the minimum legal row exceeds the width. `SpanOverflow` signals insufficient endpoint or label space. `CurveCollision` reports residual ink intersections. `SplitStemAlignment` reports incompatible formatted stem positions. `StaffSpacingLimit` reports a staff fit that still changed after four passes.

## Scope for subsequent work

This VF5 implementation lays out a continuous, measure-aligned score. Page turns, pagination and independent part layouts belong to M5. Repeat marks and destinations describe printed navigation. Playback traversal, arbitrary flagged split chords, independent staff meters and portable complex-script lyric shaping need separate work. Curve fitting uses available measured ink and reports unresolved collisions. The VF6 requirements below distinguish the source relationships from each width-specific layout.

### Independent meters

Set `continuous.independentMeters: true` to give each stave its own measure array. The staves must cover the same total duration. For example, four bars of 3/4 align with three bars of 4/4. Give each local measure a voice with its three or four quarter notes.

The formatter can wrap at a local barline where every voice can break. A held note, native beam, or tuplet keeps its members together. A local barline can also appear inside a shared formatting window. Global break requests use the first staff's local measure numbers. A repeated clef at a system edge preserves each player's position in the bar.

Use `score.meterPositions.get(score.getNote(id))` for the source staff, one-based local measure, zero-based voice and event indices, and exact tick offset `onset`. The measure-first arrays on the composition describe the shared formatting windows.
