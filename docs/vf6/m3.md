## Using the VF5 API

Call `system.getPhraseLayout()` before formatting to opt that system into phrase placement. Attach each native mark to its notes as usual. Supply the musical relationships once. The same system can then be formatted or drawn at a different width.

```js
const phrase = system.getPhraseLayout();
phrase.addVerse(treble, [
  { note: notes[0], text: 'Sum', hyphenAfter: true },
  { note: notes[2], text: 'mer', extendTo: notes[3] },
]);
phrase.route(slur);
phrase.addLane(treble, [piano, crescendo, forte]);
phrase.addLane(bass, [pedal]);
phrase.addLane(treble, [ottava], { side: 'above' });
system.format();
console.log(phrase.diagnostics);
```

Each call to `addVerse` creates a verse and returns its native annotations. A syllable stays centered on its event. A hyphen leads to the next syllable, including across intervening attacks. A melisma extends to the right edge of the specified final head. The formatter measures the entire syllable and reserves space for adjacent hyphens. The vertical pass measures the text, hyphens and extenders together. [Choir and piano examples](../../tests/engraving/phrase-studies.mjs)

| Placement | What the solver does | Author control |
| --- | --- | --- |
| Notes and close attachments | Collects heads, stems, beams, ledger lines, accidentals, clefs, signatures and supported marks. Tests rests against ink from other attacks. Moves an unpinned rest by whole spaces and stacks articulations and ornaments outward. | `pin(rest)` or `pin(mark)` keeps the registered position. `addObstacle(stave, element)` includes another positioned native element with measurable geometry. |
| Ties and slurs | Keeps endpoints and chord indices. Fits the quadratic tie ribbons first, then cubic slurs from short to long. Tests progressively larger lifts against local ink. Inner ribbons become obstacles for outer ones. | Explicit curve controls, custom tie lift controls or `pin(span)` keep the authored shape. Interleaved spans produce `CrossingSpans`. Labeled ties have partial geometry. |
| Lyrics and outside marks | Places automatic lanes in registration order, nearest the staff first on each side. Aligns dynamics on a baseline and trims a wedge around the endpoint glyphs. Measures the pedal hooks, ottava label and line. | Set `baselineSpaces` from the staff’s top line, positive downward. A native annotation’s explicit text baseline remains authoritative. Fixed lanes reserve space before routing curves. |
| Staff gaps | Fits neighboring staff envelopes with a minimum clearance, moves lower staves and refits cross-staff beams. Bridge stems and strips can obstruct a mark while spanning the gap. | `lockStaffGap(lowerStave)` preserves its configured separation. The default budget is four passes. `setPassLimit(n)` accepts 1–16. |

Inspect `diagnostics` after format. Each entry identifies the participants by element ID. A pinned collision, an unresolved collision, or an iteration limit leaves the last finite placement available for inspection. Invalid anchors, incomplete geometry, unsupported scripts and insufficient connector width have distinct codes. `bounds`, `passes` and `getLyricConnectors()` expose the result before drawing. This VF5 API targets one unbroken system of staff notes. Register outside marks with the phrase so their geometry participates. Unknown geometry produces a diagnostic for inspected participants. Bare stave lines and barlines are represented by the staff area. Whole left-to-right syllables use the renderer’s font shaping and available fonts. Lyrics requiring bidirectional layout or other complex-script handling produce a diagnostic. Verse labels, specialized elision, line-break continuations and portable text shaping remain open in the gap register.
