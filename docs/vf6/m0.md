## M0 closure

The five reviewed defects have VF5 fixes and regression assertions. Tuplet placement uses the outer annotation ink on both sides. A sloped beam can shorten its stems together to clear another voice’s head at a shared attack. Explicitly directed slurs use the stem tip when they sit on the stem side, unless the caller specifies an anchor. Simultaneous tab bends follow string order, so the upper string takes the inside path.

At M0 closure, across the original 64 Bravura SVG examples, exactly `formatter-3`, `threevoice-1`, `curve-1`, `curve-2` and `bend-2` changed against 5.2.0 in both pixels and measured geometry. Both unison controls match the release. A repeat run reproduced all 64 images and geometry digests. The separate three-spelling chord report (#523) and the wide-beam slope review carry forward under VF-006 and VF-005.

## Reproduce the report

For each review, fetch upstream and build its exact commit in a separate checkout. Build the roadmap branch from the code under review. Use the same Chrome binary, fonts, backend and fixtures for both references and the repeat. The runner checks the main and branch bundles’ embedded Git revisions. [Build guide](../build.md)

```sh
git fetch origin main
main_tree=$(mktemp -d)
git worktree add --detach "$main_tree" origin/main
(cd "$main_tree" && npm ci && npx grunt webpack:debug)
npx grunt clean:webpack_cache webpack:debug

mkdir -p build/m0-release
test -f build/m0-release/vexflow-5.2.0.tgz || gh release download 5.2.0 --pattern vexflow-5.2.0.tgz --dir build/m0-release
tar -xzf build/m0-release/vexflow-5.2.0.tgz -C build/m0-release package/build/cjs/vexflow-debug-with-tests.js
node tools/engraving-baseline.mjs build/m0-release/package/build/cjs/vexflow-debug-with-tests.js "$main_tree/build/cjs/vexflow-debug-with-tests.js"
git worktree remove "$main_tree"
```

Open the printed `build/engraving/run-…/index.html`. **Main** is the current review queue. **5.2.0** shows changes since the release. **Checkout repeat** checks determinism. Each comparison lists image and geometry changes by fixture ID. The JSON records the commits embedded in the bundles, their SHA-256 hashes and the browser version. Re-run after a merge or when upstream advances, and update the status table below. To use an installed Chrome, set `PUPPETEER_EXECUTABLE_PATH` to its executable.

The 5.2.0 tarball has SHA-256 `7443c3e99b896f982c8fbb249b48639d4bbecbddcf4bb3f0df567bc61a7fcef7`. Its debug-with-tests bundle embeds a 5.1.0 version string. The runner identifies this historical artifact by the verified bundle hash in the manifest. [5.2.0 release asset](https://github.com/vexflow/vexflow/releases/tag/5.2.0)

## Measurements before the fixes

- 64 SVG examples, each rendered on the published 5.2.0 bundle, a build from this branch based on main `31405bc5`, and a fresh second checkout page. The VF5 renderer source matched the release. The two comparisons each had **zero changed images and zero changed geometry digests**. This establishes a reproducible baseline even for a visibly faulty example.
- The runner executes each selected QUnit builder with its own assertions. It also measures paths, glyphs and transforms in draw order. Font text boxes can include substantial empty space. The altered-unison conclusions use horizontal positions of identical glyphs. A test that only asserts successful drawing gives no independent musical verdict.
- Deliberate negative controls substitute the wrong accidental sequence, supply a foreign span endpoint, overlap two measured syllables and move one outside the viewport. The existing visual comparison tests also exercise changed pixels, missing, corrupt and resized images. [Original studies](../../tests/engraving/studies.mjs) · [Visual metric tests](../../tests/node/render-metrics-tests.mjs)
- Every manifest entry inherits the VF5 reference, MIT license, fonts, backend and expected structural checks. It identifies the input by source file, module and test name. A group supplies its engraving question and gap IDs. The outcomes map flags known defects. All subjective decisions start as pending. Use the per-case review record when approving an image or requesting a change.
- Eight focused studies supplement 56 existing gallery cases. The three altered-unison passages exercise the same-pitch placement question in `accidental-placement-samepitch.ly`. The syllable/skip passage exercises the anchoring question in `lyric-hyphen-skip.ly`. Both use VF-native inputs. The remaining crosswalk entries are candidates for later fixtures. [LilyPond 2.24 index](https://lilypond.org/doc/v2.24/input/regression/collated-files.html) · [Full crosswalk](vexflow-gaps.md#initial-lilypond-case-crosswalk)
- Environment: Apple M3, arm64, macOS 27.0.1, Node 26.13.0, Chrome 157.0.8103.79, Bravura and Academico from the bundles, device pixel ratio 1. The corpus used software rasterization at a fixed integer origin. The initial scrolling capture produced up to 36 changed pixels on a repeat despite identical geometry. Moving every example to the same origin removed that variation without a pixel tolerance.
- Test bundle SHA-256: release `14d30cef7899645816d1eb50b85cf4190e20eefc709219d60c4928af7a914021`, checkout `bc979025c05416581492758ec575b0b46c09c42e615037c31826966f6903922b`. To repeat the separate six-workload benchmark, run `node tools/benchmark-scores.mjs --runs=5 --systems=4 --output=build/m0-bench`. Its original run used debug bundle `b2ddfc243fb94482fd235e7feaeeed54ccda29508c80e4fb0f7e344147bbb26b`.
