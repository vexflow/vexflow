# VexFlow User Guide

```sh
npm ci
npm run guide
```

Open <http://127.0.0.1:5174/guide/>.

```sh
npm run guide:upload -- --dry-run
npm run guide:upload
```

The upload target is <https://vexflow.com/guide/>. Building and testing do not deploy.
